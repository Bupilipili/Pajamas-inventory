Sync across devices · Not connected

Counts are saved to data/inventory.json in your GitHub repo, so your phone and computer show the same numbers. Each device needs a GitHub token once:

  1. Open github.com/settings/personal-access-tokens/new
  2. Name it "Pajama Stockroom", set an expiration, and under Repository access pick Only select repositories → Pajamas-inventory.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Tap Generate token, copy it, and paste it here.
